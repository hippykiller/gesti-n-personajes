# Gestor de Personajes e Inventario

Sistema en consola para gestionar jugadores de un videojuego y sus inventarios.
Proyecto de Estructuras de Datos, UNAB.

## Cómo ejecutarlo

    python -m venv .venv
    pip install -r requirements-dev.txt
